# Nagh VPN site

Статический сайт NaghVPN для GitHub Pages.

Основные страницы:

- `/` — главная
- `/pricing/` — тарифы
- `/offer/` — публичная оферта
- `/requisites/` — реквизиты продавца
- `/privacy/` — политика конфиденциальности
- `/terms/` — пользовательское соглашение
- `/support/` — поддержка
- `/account/` — будущая страница оформления Start и Premium
- `/payment-success/` — страница возврата после успешной оплаты
- `/payment-cancel/` — страница отмены оплаты

Домен: naghvpn.ru
