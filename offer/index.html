4. Активация доступа

После успешной оплаты Premium-доступ активируется в аккаунте пользователя, связанном с e-mail, указанным при входе или оформлении заказа.

5. Возвраты

Возврат денежных средств рассматривается по обращению пользователя в поддержку.

Если услуга не была оказана из-за технической ошибки на стороне сервиса, пользователь может запросить возврат или продление периода доступа.

Если доступ был активирован и пользователь фактически пользовался сервисом, возврат может быть ограничен фактически оказанным объёмом услуги, если иное не требуется применимым законодательством.

6. Ограничения использования

Пользователь обязуется не использовать сервис для противоправных действий, рассылки спама, атак, мошенничества, распространения вредоносного ПО и иных нарушений закона.

Сервис предназначен для защиты соединения и приватности пользователя.
