# Изменения Happ-подписки

- В личном кабинете больше нет действия "создать Happ-подписку" как пользовательской кнопки.
- При входе в личный кабинет сайт пытается автоматически создать одну Happ-подписку, если:
  - у аккаунта активный платный тариф;
  - у аккаунта ещё нет Happ-подписки;
  - есть свободный слот устройства.
- Пользователь видит одну постоянную ссылку и кнопку "Скопировать ссылку на подписку".
- Кнопка удаления Happ-подписки из интерфейса убрана.
- Старая кнопка в карточке "Через Happ" теперь только копирует существующую ссылку.

Важно: backend всё ещё технически позволяет создать/удалить подписку через API. Для полного запрета нужно отдельным патчем сделать backend-эндпоинт идемпотентным и скрыть DELETE/POST-дубли на уровне API.
