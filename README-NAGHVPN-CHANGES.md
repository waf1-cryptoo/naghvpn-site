# Изменения NaghVPN

- публичная тарифная модель: Start, Plus и Premium;
- Start: 1 устройство, без кодов подключения и Happ, 149 / 390 / 1190 ₽;
- Plus: 3 устройства, VLESS + Reality, раздельное туннелирование, коды подключения и Happ, 299 / 749 / 2390 ₽;
- Premium: 5 устройств, VLESS + Reality, раздельное туннелирование, коды подключения и Happ, 449 / 1090 / 3490 ₽;
- отдельный публичный PC-тариф убран;
- обновлены главная, тарифы, оплата, соглашение и инструкция Happ;
- ссылки Android/iOS оставлены заглушками до публикации приложений.
